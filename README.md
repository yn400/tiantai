# 天台 · Tiantai

> 一个温柔的 AI 陪伴桌面应用。
> 在天台看落日，让风替你说不出口的话。

「天台」把心情记录、呼吸练习、AI 陪伴、环境声音和写给未来的信，装进一个安静、唯美、本地优先的小世界。它不评判你，不催你变好——它只是在。

---

## ✨ 特性

- 🌄 **今天页** —— 时段风景横幅（Ken Burns 缓推 + 滚动视差 + 光尘）、二十四节气与月相徽章、每日一言、五档心情打卡
- 🌬 **呼吸** —— 4-4-6 节律引导、粒子随呼吸涨落、练习记录
- 💬 **陪我说说** —— SSE 流式对话（逐字浮现、可随时打断），支持 DeepSeek / OpenAI / 通义千问 / Kimi / 智谱 五家模型
- 🎵 **声音** —— WebAudio 实时合成的雨/风/浪/篝火/夜城/白噪音，可叠加混音、睡眠定时
- 💌 **天台信箱** —— 写给未来的信，到点才能拆
- 🎨 **天台画板 / 感恩墙 / 记忆时间线** —— 涂鸦随风飘散、温暖小事上墙、心情足迹回溯
- 🏆 **成就时刻感** —— 解锁瞬间有庆祝反馈；连续记录按真实自然日计算
- 🔒 **隐私优先** —— BYOK（自带 Key）：模型 Key 只存本地，数据只在你手里，一键导出

## 🚀 快速开始

```bash
# 环境要求：Node.js ≥ 18
npm install

# 浏览器开发模式（PWA）
npm run dev            # http://localhost:5173

# Electron 桌面模式
npm run electron:dev

# 打包 Windows 安装包
npm run dist
```

首次使用：进入「我的 → AI 模型」，选择模型商并填入**你自己的 API Key**
（如 [DeepSeek](https://platform.deepseek.com/api_keys)，智谱 GLM-4 Flash 免费）。Key 仅存储在本地浏览器中。

## 🏗 技术栈

| 层 | 选型 |
|---|---|
| 桌面壳 | Electron |
| 前端 | React 19 · TypeScript · Vite |
| 状态 | Zustand（persist） |
| 样式 | Tailwind CSS |
| 动效 | 自研 FX 引擎（单 rAF 调度 / DPR 感知 / dt 归一化）+ WebAudio 合成 |

## 📁 结构速览

```
electron/          主进程（窗口、权限策略、单实例锁）
src/
  fx/engine.ts     统一 Canvas 特效调度器
  stores/          Zustand 全局状态
  components/      页面与氛围组件（Stars/WeatherFX/MiniPlayer…）
  utils/           AI 客户端、语音、声音引擎、月相节气…
docs/              发布关卡清单
```
